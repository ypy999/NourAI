## 1. البنود المكتملة والمختبرة
- [x] إغلاق كافة الثغرات الأمنية الـ 18 (`SEC-01`–`SEC-18`).
- [x] إغلاق `CQ-01` (عزل إيقاف التوليد حسب المستخدم) و`CQ-02` (التحقق من معاملات التوليد وإرجاع `400`).
- [x] إضافة فهارس SQLite وإصلاح N+1 وإصلاح تصادم `doc_id` (`CQ-04`, `CQ-05`, `CQ-09`).
- [x] تفعيل KV-Cache وتحقيق تسريع **4.43x** مع تطابق عددي تام (`CQ-06`).
- [x] تشديد CSP (`object-src 'none'`, `base-uri 'self'`, `frame-ancestors 'none'`).
- [x] تأمين `Dockerfile` بمستخدم غير جذري `appuser` وصلاحيات `0700` لمجلد البيانات.
- [x] إنشاء `requirements.lock` و`.github/workflows/ci.yml`.
- [x] إضافة اختبارات E2E والتزامن والتحقق من JS الفعلي عبر `Node.js`.

---

## 2. البنود والمتطلبات المتبقية قبل النشر العام (Action Required)
1. **تشغيل `pip-audit` الفعلي في بيئة متصلة / CI:** لم يُشغّل `pip-audit` محلياً لعدم تثبيته في `.venv`.
2. **إزالة `'unsafe-inline'` من `CSP` بالكامل:** يتطلب نقل السكربتات/الأنماط المضمنة ومعالجات `onclick` الثابتة في `ui/index.html` إلى ملفات `.js`/`.css` منفصلة.
3. **ضبط متغيرات بيئة الإنتاج:** تعيين `NOURAI_SECRET_KEY` (مفتاح عشوائي طويل) و`NOURAI_TRUSTED_PROXIES` (عناوين Reverse Proxy مثل Render/Cloudflare) في لوحة النشر (`render.yaml`).
4. **اختبارات متصفح حقيقية (Playwright) وتوحيد Python `3.11` محلياً:** البيئة المحلية تعمل على Python `3.15.2` دون `playwright` مثبت، بينما الإنتاج يستهدف Python `3.11`.
5. **نشر خلف Reverse Proxy بـ TLS حقيقي:** خادم `ThreadingHTTPServer` المدمج مناسب للتطوير/الحمولات الخفيفة؛ للنشر العام عالي الحمل يُنصح بوضعه خلف Nginx/Caddy/Render TLS Termination.
