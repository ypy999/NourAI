## 3. ضوابط منع هدر حصص GPU المجانية المطبقة برمجياً

1. **فحص البوابة قبل الحجز (`production_launcher.py` + `multi_platform_adapter.py`):** يُمنع تشغيل `125M` أو `350M` ما دامت البيانات `DATA_NOT_READY` أو لم تتوفر البطاقة.
2. **التقدير المسبق للذاكرة والزمن (`estimate_memory_and_time`):** يُحسب استهلاك VRAM والدُفعة ووقت الجلسة قبل بدء أول خطوة لتجنب أخطاء `CUDA OOM` المكلفة للحصة.
3. **حفظ Checkpoints ذري + استئناف تلقائي + حارس استقرار (`TrainingStabilityWatchdog`):** يحمي من فقدان ساعات تدريب عند انقطاع الجلسة أو ارتفاع `grad_norm` أو `NaN/Inf`.
4. **عزل الاختبارات والتحقق محلياً على `jebrex-micro`:** تُختبر كل التعديلات الكودية محلياً على CPU (`< 15s`) قبل إطلاق أي دقيقة على GPU سحابي.
