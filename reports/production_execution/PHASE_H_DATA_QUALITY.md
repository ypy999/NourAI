## 3. خط المعالجة الوقائية المطبّق في `data/phase_h_quality.py`

قبل تدفق أي شظية جديدة (Shard) إلى التدريب السحابي، يطبق خط الجودة إلزامياً:
1. **`clean_text_html_and_noise()`:** إزالة `<script>`/`<style>` ووسوم HTML وفك الكيانات وإزالة أسطر القوالب المتكررة (`Cookie Policy`, `All Rights Reserved`) والمحارف التحكمية، مع تطبيع `Unicode NFC`.
2. **`scrub_pii()`:** رصد وإخفاء البريد الإلكتروني `[REDACTED_EMAIL]`، أرقام الهواتف المنسقة `[REDACTED_PHONE]` (دون إفساد السنوات مثل `2026`)، عناوين `IPv4` `[REDACTED_IP]`، أرقام البطاقات المتحققة بخوارزمية Luhn `[REDACTED_CARD]`، ومفاتيح API (`sk-`, `AIza`, `ghp_`, `AKIA`) `[REDACTED_SECRET]`.
3. **بوابة التراخيص:** استبعاد أي مجموعة غير واضحة الترخيص التجاري/إعادة التوزيع (عدم إدخال أي بيانات مجهولة المصدر أو سجلات محادثات مستخدمين دون موافقة صريحة).

## 4. خطة التدفق السحابي للوصول إلى `DATA_READY` (`>= 3B` توكن متوازن)

بسبب محدودية القرص المحلي (`C: 6.20 GiB` فقط)، يُحظر تنزيل مليارات التوكنات محلياً؛ وبدلاً من ذلك تُبث المصادر المرخّصة التالية مباشرةً داخل جلسة `Kaggle / Lightning AI` إلى `Cloudflare R2`:

1. **Wikimedia Dumps (`ar / en / fr`):** ترخيص `CC-BY-SA-4.0` — يعالج العجز العربي فوراً (`> 5.5B` توكن متاحة).
2. **FineWeb-2 (`ar / fr`) وFineWeb-Edu (`en`):** ترخيص `ODC-By-1.0` — تدفق مباشر لشظايا منظفة (`1B` عربي + `1B` إنجليزي + `1B` فرنسي).
3. **The Stack v2 (Permissive Subset فقط: `MIT / Apache-2.0 / BSD`):** لرفع كفاءة البرمجة.
4. **OpenAssistant-2 (`OASST2`, `Apache-2.0`):** لمحاذاة المحادثات متعددة الأدوار في المرحلة SFT.
