# دليل المستخدم / User Guide / Guide Utilisateur — NourAI

## العربية (RTL)
يدعم نظام NourAI المحادثة باللغة العربية مع محاذاة تلقائية من اليمين إلى اليسار (RTL)، وتخصيص معاملات التوليد (`Top-P`, `Top-K`, `Temperature`).

## English (LTR)
NourAI provides local-first multilingual conversation with session history, streaming responses, and adjustable sampling controls.

## Français (LTR)
NourAI offre une interface multilingue locale avec historique des sessions, génération progressive et contrôle complet des paramètres.
