# Jebrex AI — Resource Plan (خطة الموارد والحدود الآمنة)

## 1. حدود البيئة المحلية الحالية (Hard Operational Ceilings)

| المورد | السعة الكلية | المتاح فعلياً (`2026-11-24`) | الحد الأقصى الآمن المسموح به في هذه الجلسة |
|---|---:|---:|---:|
| المعالج (CPU) | `2` نواة / `4` خيوط (`i3-10110Y`) | `100%` | تشغيل متسلسل (`cpu_threads=2`) لتجنب تجميد النظام |
| الذاكرة العشوائية (RAM) | `7.89 GiB` | `~2.51 GiB` | سقف استهلاك العملية `< 1.2 GiB` |
| GPU / VRAM | لا يوجد (`CUDA=False`) | `0 GiB` | `0 GiB` (CPU FP32 فقط) |
| التخزين `C:` (مساحة العمل) | `60.0 GiB` | `6.95 GiB` | سقف الإضافات الجديدة `< 100 MiB` (ملفات كود، بيانات نظيفة مصغّرة، نقطة حفظ تجريبية واحدة، وتقارير) |
| التخزين `D:` (خارج مساحة العمل) | `58.6 GiB` | `14.70 GiB` | للقراءة/تشغيل `.venv` فقط؛ عدم الكتابة خارج مساحة العمل |
